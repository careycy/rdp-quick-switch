# 远程桌面快切 (RdpQuickSwitch)

> A tiny always-on-top float bar for instantly switching between multiple Windows remote-desktop (mstsc) sessions. 零依赖、单文件、双击即用。

屏幕左上角常驻一个**最高置顶**的迷你浮窗，实时显示当前打开的远程桌面（mstsc）窗口数量；鼠标移上去自动展开窗口列表，**点击任意一行即可切换**到对应远程桌面。专为多远程桌面日常办公设计。

## 使用方法

1. 双击 `远程桌面快切.exe` 启动（无需安装，零依赖，支持 Win7/Win10/Win11）。
2. 屏幕左上角会出现一个小浮窗：`⇆ N`（N = 当前远程桌面窗口数，0 时灰显）。
3. **鼠标移上去** → 浮窗向下展开，列出每个远程桌面窗口的标题，当前活跃窗口高亮。
4. **点击某一行** → 立即切换到该远程桌面（最小化的会自动还原）。
5. 鼠标移开后浮窗自动收起。
6. **按住浮窗拖动**可挪位置，位置会自动记忆（保存在 `floatpos.txt`）。

### 托盘菜单

程序启动后在右下角托盘有图标（蓝色双向箭头）：

- **隐藏/显示浮窗**：临时收起浮窗（双击托盘图标同效）
- **开机自动启动**：勾选后写入注册表 HKCU Run，开机免手动
- **退出**：彻底关闭

## 置顶保障

浮窗每秒自动校正一次置顶状态。即使 RDP 会话重连、系统重排窗口 Z 序导致置顶位丢失，**最多 1 秒内自动恢复**到最顶层，不会被远程桌面窗口盖住。

## 识别哪些窗口？

默认识别 **Windows 自带的"远程桌面连接"（mstsc.exe）** 打开的所有窗口。

想同时识别其他远控软件（ToDesk、向日葵、AnyDesk 等），编辑 exe 旁边的 `targets.txt`，每行写一个进程名（可不带 .exe，`#` 开头为注释），保存后约 1 秒自动生效。例如：

```
ToDesk.exe
SunloginClient.exe
```

## 重新编译

改了 `Program.cs` 后，双击 `build.bat` 即可重新编译——它调用 Windows 自带的 .NET Framework 编译器，**无需安装任何开发环境**。

## 文件说明

| 文件 | 说明 |
|---|---|
| `远程桌面快切.exe` | 主程序（唯一需要的文件） |
| `targets.txt` | 可选配置：扩展识别的进程名 |
| `floatpos.txt` | 自动生成：浮窗位置记忆 |
| `Program.cs` / `build.bat` | 源码与编译脚本 |

## 常见问题

- **浮窗不见了？** 检查托盘是否设为"隐藏浮窗"；或确认没有其他置顶窗口恰好压在左上角。
- **单实例**：重复双击 exe 会提示"已经在运行"，不会开多个。
- **切换没反应？** 目标窗口若已关闭，列表会在 1 秒内自动刷新移除。
- **build.bat 打开乱码？** 该脚本为 GBK 编码以适配中文版 cmd，仅显示文字乱码时不影响编译。

## 项目结构

单文件源码 `Program.cs`（约 600 行，C# 5 语法以兼容系统自带编译器），分五个部分：

| 类 | 职责 |
|---|---|
| `Win32` | Win32 API P/Invoke（枚举窗口、进程名查询、前台切换、置顶） |
| `WindowScanner` | 定时枚举顶层窗口，按进程名匹配远程桌面窗口；支持 targets.txt 热更新 |
| `Switcher` | 窗口切换（还原最小化 + 绕过前台锁定限制的 SetForegroundWindow） |
| `FloatWindow` | 自绘浮窗 UI（收起/展开两态、悬停、拖动、DPI 适配、置顶自愈） |
| `TrayContext` | 托盘图标与菜单（显隐浮窗、开机自启、退出） |
